# backend/src/taxonomy

Read `/AGENTS.md` and `/backend/AGENTS.md` first.

`catalog.ts` is the Uber Eats chip set and the US/Canada metro grid. Adding a vertical means a new category with `iconKey` that already exists in the guest app art, plus a Booksy `serviceStyle` (rental, tour, ticket, appointment). Do not add a metro you cannot name with a real region code.
