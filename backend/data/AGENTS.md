# backend/data

Read `/AGENTS.md` and `/backend/AGENTS.md` first.

`outset.db` is local SQLite. Do not commit it. It is the operator source of truth for unclaimed profiles, scrape history, and outreach drafts.

`claim-index.json` is generated by `npm run sync` (or `npm run claim-index`) and committed. It carries hashed on-file emails and owned domains per listing, never the addresses themselves. The API reads it to decide who may claim a listing.

`public/mail/unsub.json` is the outreach suppression list (email hashes only). The API writes it when someone hits `/unsubscribe`. The Mac send job reads it and skips those addresses.
