# src/data

Read `/AGENTS.md` first.

This is the catalog. Live listings can be booked. Unclaimed records cannot. Never mix those two collections.

When you edit a listing, keep `facts`, `policy`, and `addons` aligned with `blurb`. The agent reads all three.

When you add an unclaimed operator, only store facts from that business's own site. Use `gap` for anything unpublished.

`types.ts` is the contract. Update it before inventing fields.
