# src/data

Read `/AGENTS.md` first.

`listings.ts` is the claimed-slot catalog and stays empty for now. The guest Instant Book grid is `unclaimed.ts` plus `unclaimedNational.ts`: real operators, facts from their own sites. Do not invent prices, ages, waivers, or slots. Do not tell guests they are unclaimed. Ratings on cards are public review snapshots (Google, Yelp, or TripAdvisor). Omit the score if we do not have one. `contacts.ts` is generated by `npm run backend:sync`. Do not fill missing phones or hours by hand. `metros.ts` city-center coords are for distance only, not operator pins.

Never mix those two collections. Never add a demo operator.

`contacts.ts` is generated by `npm run backend:sync`. It holds each operator's public phone, email, address, hours and site, keyed by domain. Do not edit it by hand. If a field is null, the site did not publish it.

`/public/catalog.json` is generated by `npm run backend:sync` and fetched at startup. `src/lib/catalog.ts` merges it behind the hand-verified seeds, so a seed with the same domain always wins. Never edit the JSON by hand.
